ManageRent4U V111 — EPC persistence correction

Cause: V95 setup does not define a tenants.epc_label column. The V110 tenant
wizard included this alias in every save, even when blank; the atomic SQL save
then tried to write a column that did not exist. The earlier address correction
did not address this separate field.

Correction:
- Stop passing epc_label to the tenant SQL save function.
- Keep EPC grade in the existing __MR4U_CONTRACT metadata in stay_notes, which
  already stores it. Accept both older top-level EPC inputs and new form metadata.
- Retain lease dates, indexation preference, private notes, identity/cost metadata.
- When reopening, prefer saved contract EPC metadata over an old optional column;
  an explicit blank value clears an earlier grade.
- Recurring-charge edits preserve existing contract/EPC metadata.
- Browser save payload excludes the unsupported EPC alias. The backend normalizer
  remains compatible with the older V110 client. No new API or SQL migration.
